Giriş

CarLog AZ avtomobil xərcləri, servis tarixçəsi, yanacaq, sənədlər, xatırlatmalar və yolüstü kömək məlumatlarını idarə etmək üçün hazırlanmış mobil tətbiqdir.

Bu sənəd tətbiqin hansı məlumatlardan istifadə etdiyini, bu məlumatların nə üçün lazım olduğunu və necə qorunduğunu izah edir.

Toplanan və saxlanan məlumatlar

Tətbiq daxilində istifadəçinin özü əlavə etdiyi məlumatlar cihazda lokal saxlanılır:

  • profil məlumatları: ad, soyad, telefon, email, şəhər, doğum tarixi və profil şəkli;
  • avtomobil məlumatları: marka, model, il, yürüş, qeydiyyat və texniki məlumatlar;
  • servis, yanacaq, xərc, sığorta, texniki baxış, təkər, sənəd və qaraj qeydləri;
  • istifadəçinin əlavə etdiyi şəkil URI-ləri və qeydlər;
  • tətbiq ayarları: dil, tema, vahid, valyuta və bildiriş seçimləri.

Hazırkı versiyada bu məlumatlar CarLog AZ serverinə göndərilmir və hesab/sinxronizasiya sistemi aktiv deyil.

İcazələr

  • İnternet icazəsi: Firebase konfiqurasiyası, app daxili bannerlər və push bildirişləri kimi funksiyalar üçün istifadə oluna bilər.
  • Məkan icazəsi: GPS sürətölçən funksiyasında cari sürəti hesablamaq üçün istifadə olunur. Fon məkan izlənməsi edilmir.
  • Bildiriş icazəsi: servis, sığorta, texniki baxış və oxşar xatırlatmaları göstərmək üçün istifadə olunur.

Firebase və texniki məlumatlar

Tətbiqdə app daxili bannerlər, push bildirişləri və konfiqurasiya üçün Firebase Cloud Messaging, Firebase Remote Config, Firebase Analytics, Firebase Firestore və Firebase In-App Messaging inteqrasiyası nəzərdə tutulub.

Bu sistemlər aktiv olduqda Firebase cihaz tokeni, tətbiq/cihaz texniki məlumatları və SDK diaqnostika məlumatları Google/Firebase xidmətləri tərəfindən işlənə bilər. Bu məlumatlar bildirişlərin çatdırılması, tətbiq konfiqurasiyası, app daxili mesajlar və texniki sabitlik məqsədləri üçün istifadə olunur.

Məlumat paylaşımı

Hazırkı versiyada istifadəçinin lokal daxil etdiyi avtomobil və profil məlumatları üçüncü tərəflərlə paylaşılmır.

Firebase SDK-ları aktiv olduğu üçün, Firebase xidmətlərinin texniki məlumat emalı Google/Firebase infrastrukturunda həyata keçirilə bilər. CarLog AZ bu məlumatları reklam profili yaratmaq və ya şəxsi avtomobil qeydlərini satmaq üçün istifadə etmir.

Məlumatların silinməsi

İstifadəçi tətbiqdə daxil etdiyi məlumatları tətbiq daxilindən dəyişə və ya silə bilər. Cihazdan tətbiq silindikdə lokal məlumatlar da cihazdan silinir.

Gələcəkdə server sinxronizasiyası aktiv edilərsə, hesab və məlumat silinməsi üçün ayrıca mexanizm əlavə olunacaq.
